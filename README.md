# 계약제교원 채용 도우미

교감(인사담당자)이 **기간제교원·강사**를 채용할 때 상황에 맞는 절차를 판별하고, 인사자문위원회 공문을 한글(hwpx) 파일로 만들어 주는 웹서비스입니다.

👉 **사용하기: https://gyo6star8i.github.io/contract-teacher-helper/**

> 기준: 「2026 경상북도 계약제교원 운영 지침(2026. 2. 1. 시행)」, 「계약제교원 운영 관련 Q&A(2026. 2.)」, 「계약제교원 관련 법령」
> 참고용 도구입니다. 최종 판단은 지침 원문과 교육(지원)청에 확인하세요.

## 기능

| 메뉴 | 내용 |
|---|---|
| ① 상황 판별 | 결원 기간·사유, 공고 진행 상황, 채용 예정자(나이·퇴직·자격)를 넣으면 채용 신분(기간제교원/전일제강사/시간강사), 공고 생략 가능 여부, 자격 확대 가능 여부, 인사자문위원회 필요 여부를 근거 조항과 함께 알려 줍니다. 긴급 결원에 연령 초과자를 채용하려는 경우 등은 **2단계 채용(긴급 강사 + 2차 공고)** 으로 안내합니다. |
| ② 절차 안내 | 판정된 경로별 단계와 날짜(공고 마감일 등), 구비 서류 체크리스트 |
| ③ 공문 만들기 | **인사자문위원회**: 개최 기안 / 개최 결과 기안 / 회의록<br>**채용 서류**: 채용계획 기안(참고자료 2) / 채용 계획(참고자료 3) / 채용 공고문(참고자료 4) / 채용계약서(서식 14)·시간강사 근로계약서(서식 15) / 기간제교원 임용사항 보고(서식 21)<br>모두 hwpx(맑은 고딕 11.5pt, 줄간격 103%). 판별 결과가 문구·날짜·자격 확대 내용에 자동 반영되고 내려받기 전에 고칠 수 있습니다. 전형 일정은 공고일만 넣으면 자동 계산(접수 마감은 공고일 제외 3일, 이후 일정은 평일). |
| ④ 육아휴직·계약 해지 | **육아휴직**: 자녀 요건(만 8세 이하·초2 이하·임신), 같은 학교 6개월 근무, 신청 기한(30일/7일 전), 남은 사용 기간, 계약 종료 영향 확인 → 육아휴직원(서식 25)·허가 기안·복직원(서식 26). 대체 기간제교원 채용 판별로 바로 연결<br>**중도 계약 해지**: 사유별로 30일 전 서면 예고 기한(3개월 미만 생략), 귀책 사유 인사자문위원회 소명 절차(10일 전 통지), 성비위 선행 절차, 5일 이내 보고 기한 → 해지(예고) 확인서(서식 28)·중도 해지 보고 기안·인사자문위원회 개최 기안 |
| ⑤ 계산기 | 임용 상한 연령(62·65·70세), 1개월·6개월 기간(민법 제160조), 연가·병가 일수, 시간강사 수당, 공고 마감일 |
| ⑥ 지침·Q&A 검색 | 지침 본문(조항 단위)과 Q&A 39문항 키워드 검색. 판별 결과의 근거 칩(예: `지침 p.19`, `Q&A 16`)을 누르면 원문으로 이동 |

## 개인정보 원칙

- **서버가 없습니다.** GitHub Pages 정적 사이트이며, 입력 내용은 브라우저 안에서만 처리되고 어디로도 전송되지 않습니다.
- hwpx 파일도 브라우저에서 직접 만들어 내려받습니다(JSZip, 저장소에 포함).
- 접속 통계·추적 코드·외부 스크립트를 쓰지 않습니다.
- 브라우저에 저장하는 것은 **학교 정보(학교명·주소·전화 등)뿐**입니다. 채용 예정자 생년월일, 위원 성명 등은 저장하지 않습니다.
- 공문의 사람 이름은 ○○○로 두고, 내려받은 한글 파일에서 직접 입력하는 것을 권장합니다.
- 이 저장소의 템플릿·예시에는 실제 인명이 들어 있지 않습니다. **실제 공문·회의록을 저장소에 올리지 마세요.**

## 구조

```
index.html            화면
css/style.css
js/rules.js           판별 엔진(지침 규칙) ← 지침 개정 시 주로 수정
js/docs.js            판별 결과 → 인사자문위원회 공문 문구
js/docs2.js           채용 계획·공고문·계약서·임용 보고 문구
js/rules2.js          육아휴직·중도 계약 해지 판정
js/docs3.js           육아휴직·중도 해지 문서 문구
js/app2.js            육아휴직·계약 해지 화면
js/hwpx.js            hwpx 템플릿 채우기
js/app.js             화면 동작
data/guide.json       지침 본문(쪽·문단 단위)
data/qa.json          Q&A 39문항
templates/*.hwpx      공문 템플릿(자리표시자 포함)
tools/build_templates.py  템플릿 생성 스크립트(python-hwpx)
tools/extract_pdf.py      지침·Q&A PDF → data/*.json (pdfplumber)
vendor/jszip.min.js   JSZip 3.10.1 (MIT)
```

## 지침이 바뀌면

1. `js/rules.js`의 `RULES` 상수(상한 연령, 공고 기간 등)와 `judge()` 분기를 고칩니다.
2. 새 지침·Q&A PDF로 `data/*.json`을 다시 만듭니다: `python tools/extract_pdf.py 지침.pdf QA.pdf` (지침 쪽 번호 대응은 스크립트 안의 `pg=i-4`를 확인)
3. 상단 배지 문구(`RULES.version`)를 바꿉니다.
