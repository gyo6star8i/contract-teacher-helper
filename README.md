# 계약제교원 채용 도우미

교감(인사담당자)이 **기간제교원·강사**를 채용할 때 상황에 맞는 절차를 판별하고, 인사자문위원회 공문을 한글(hwpx) 파일로 만들어 주는 웹서비스입니다.

👉 **사용하기: https://gyo6star8i.github.io/contract-teacher-helper/**

> 기준: 「2026 경상북도 계약제교원 운영 지침(2026. 2. 1. 시행)」, 「계약제교원 운영 관련 Q&A(2026. 2.)」, 「계약제교원 관련 법령」
> 참고용 도구입니다. 최종 판단은 지침 원문과 교육(지원)청에 확인하세요.

## 기능

| 메뉴 | 내용 |
|---|---|
| ① 상황 판별 | 결원 기간·사유(**여러 개 선택 가능**: 병가+연가+휴직 등, 사유별 관련 법령 자동 표시), 공고 진행 상황, 채용 예정자(나이·퇴직·자격)를 넣으면 채용 신분(기간제교원/전일제강사/시간강사), 공고 생략 가능 여부, 자격 확대 가능 여부, 인사자문위원회 필요 여부를 근거 조항과 함께 알려 줍니다. 긴급 결원에 연령 초과자를 채용하려는 경우 등은 **2단계 채용(긴급 강사 + 2차 공고)** 으로 안내합니다. |
| ② 절차 안내 | 판정된 경로별 단계와 날짜(공고 마감일 등), 구비 서류 체크리스트 |
| ③ 공문 만들기 | **인사자문위원회**: 개최 기안 / 개최 결과 기안 / 회의록<br>**채용 서류**: 채용계획 기안(결원 사유별 「교육공무원법」 제32조제1항 각 호·「교육공무원임용령」 제13조제1항 각 호 자동 기재) / 채용 계획 / 채용 공고문 / 계약서(서식 14·15) / 임용사항 보고(서식 21). 접수 방법(방문·우편·이메일)과 채용서류 반환 청구 기간(14~180일) 선택, 이메일 접수만이면 반환 대상 아님(채용절차법 제11조제1항 단서) 문구 자동 반영<br>**최종합격자 서류**: 신분·계약 기간·연장 여부에 맞춰 서식 9·10·17·19·20·22·23·24를 골라 한 파일(서식별 쪽 나눔)로, 따로 받을 서류와 생략 가능 서류 안내<br>**자체 점검표**: 채용 점검표(서식 29)·운영 현황 점검표(서식 30) |
| ④ 심사·평가 | **채용 심사 점수 집계**: 위원별 점수 → 평균·배수·과락·동점자 처리, 집계표(서식 5·7)·심사 결과 기안, 평가표(서식 3·4·6·8)<br>**호봉 획정**: [별지 제16호 서식] 호봉획정표 방식, 기존 호봉획정표 불러오기(hwpx·xlsx·PDF) 후 수정, 엑셀(.xlsx, 수식 포함) 저장((1)~(18), 1년=12월·1월=30일), 자격별 기산호봉·학력별 가감년수 표, 경력환산율표(지침 p.82~84), 겹치는 경력은 유리한 것 하나만, 강사는 학년도별 기준시간(44·43·42·40h)으로 주당·총 시간 환산, 호봉상한제(14호봉), 잔여월수·차기승급일 → 호봉획정표(.hwpx)<br>**근무실적 평가(서식 18)**: 등급 선택 → 총점·종합등급, 의무교육 미이수·동의서 확인 |
| ⑤ 근무 중 관리 | **연장 계약**: 동일교 4년 상한, 공백·결원 동일성, 자격 확대 채용자 연장 불가, 6개월 이상 연장 요건, 생략 가능 서류, 연가 누적, 나이스 처리 → 인사자문위원회 공문·연장 계약서로 연결<br>**육아휴직**: 요건 확인 → 육아휴직원(서식 25)·허가 기안·복직원(서식 26)<br>**중도 계약 해지**: 예고 기한·소명 절차·보고 기한 → 해지(예고) 확인서(서식 28)·보고 기안·인사자문위원회 기안 |
| ⑥ 계산기 | 임용 상한 연령, 1개월·6개월 기간, 연가·병가 일수, 시간강사 수당, 공고 마감일, **정근수당**(14호봉 제한 시 근무연수 5년), **퇴직금**(평균임금·통상임금 비교, 3개월 일수 자동), **강사 주휴수당** |
| ⑦ 지침·Q&A 검색 | 지침 본문(조항 단위)과 Q&A 39문항 키워드 검색. 판별 결과의 근거 칩(예: `지침 p.19`, `Q&A 16`)을 누르면 원문으로 이동 |

모든 한글 파일은 hwpx(맑은 고딕 11.5pt, 줄간격 103%)로 브라우저에서 바로 만들어집니다.

## 개인정보 원칙

- **서버가 없습니다.** GitHub Pages 정적 사이트이며, 입력 내용은 브라우저 안에서만 처리되고 어디로도 전송되지 않습니다.
- hwpx 파일도 브라우저에서 직접 만들어 내려받습니다(JSZip, 저장소에 포함).
- 접속 통계·추적 코드·외부 스크립트를 쓰지 않습니다.
- 브라우저에 저장하는 것은 **학교 정보(학교명·주소·전화 등)뿐**입니다. 채용 예정자 생년월일, 위원 성명 등은 저장하지 않습니다.
- 공문의 사람 이름은 ○○○로 두고, 내려받은 한글 파일에서 직접 입력하는 것을 권장합니다.
- 이 저장소의 템플릿·예시에는 실제 인명이 들어 있지 않습니다. **실제 공문·회의록을 저장소에 올리지 마세요.**

## 지침이 바뀌면

1. `js/rules.js`의 `RULES` 상수(상한 연령, 공고 기간 등)와 `judge()` 분기를 고칩니다.
2. 새 지침·Q&A PDF로 `data/*.json`을 다시 만듭니다: `python tools/extract_pdf.py 지침.pdf QA.pdf` (지침 쪽 번호 대응은 스크립트 안의 `pg=i-4`를 확인)
3. 상단 배지 문구(`RULES.version`)를 바꿉니다.
